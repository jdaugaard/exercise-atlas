# Contributing to Exercise Atlas

Anyone can contribute. Open a pull request with a new exercise, an illustration, a correction, or a code change. For a new exercise, start with the [authoring skill](.agents/skills/exercise-atlas-authoring/SKILL.md), leave the entry as a draft, and run `npm run docs:generate` and `npm run verify`.

You keep the rights you hold in your contribution. By submitting it, you make it available to everyone under the [same license](LICENSE) as the material you are contributing to. Catalog entries, illustrations, and documentation use CC BY-NC 4.0. Code and skills use the Exercise Atlas Noncommercial Software and Skills License. Please submit material you have permission to share on those terms and credit its creators.
